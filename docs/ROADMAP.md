# DeskDaily 后续产品路线图

这份路线图把“好看”放在“可靠”之后的正确位置：动态效果应服务于状态理解，视觉装饰不能遮挡任务、破坏点击或增加提醒噪音。

## 近期：可靠性与交互收口

### 提醒调度

当前界面刷新使用 15 秒轮询。下一步应把每个有效任务时段注册为 `UNCalendarNotificationTrigger`，开始和结束各一个通知；轮询只负责 now 线、跨天状态和兜底。这样应用重启、后台或 Mac 从睡眠恢复后，提醒仍然有机会按系统调度执行。

同时要修正：

- 提醒不能只检查当前计划表，所有计划表的有效任务都应统一调度。
- `activeSheetId` 启动时必须校验属于 `sheets`，失效时回退到第一张表。
- 时段跨午夜要明确策略：初期可禁止跨日时长；支持跨日后必须用目标日期计算结束时间。
- 导入、恢复和重复规则修改要有结构校验及错误反馈。

### 交互

- 给 `⌘N`、`Esc`、上下选择、空格完成补上可见焦点和 VoiceOver 标签。
- 删除、覆盖 AI 清单、导入备份统一保留撤销或确认路径。
- 统计页明确“当前计划表”或“全部计划表”的口径，标题中始终显示范围。
- API Key 逐步迁移到 macOS Keychain，导出备份默认脱敏。

## 中期：学生与工作者模板

先做静态内置模板目录，而不是把内置模板直接混进用户模板数组。每个模板提供预览、适用场景和可勾选任务，用户确认后新建计划表或追加当前表。

### 学生

- 上课日：通勤、课前预习、课程、课堂笔记、作业专注块、当天复习、运动、睡眠。
- 考试周：按科目、考试日期、可用小时和当前掌握程度生成复习块，强制保留吃饭、休息和睡眠。
- 变量：上课开始时间、通勤时长、晚间睡眠时间。

### 工作者

- 标准工作日：通勤、邮件整理、两个深度工作块、会议、午休、收尾复盘、运动。
- 轮班/弹性工作：班次开始、通勤时间、睡眠时间由实例化向导填写，不写死 9 点到 18 点。
- 变量：上班开始时间、午休时长、下班时间、运动偏好。

详细模板见 [TEMPLATES.md](TEMPLATES.md)。

## 动态效果原则

- 新增任务从底部淡入，删除向右淡出，窗口高度平滑变化。
- 当前进行中的时段使用绿色状态，但动画只做轻微呼吸，不持续制造干扰。
- 完成最后一项时庆祝一次，支持 Reduce Motion。
- AI 等待使用骨架或流式开始反馈，避免长时间静止。
- 闲置淡化、迷你胶囊和边缘磁吸都必须可关闭，并不能拦截滚动和点击。

## 远期：数据模型稳定后

- 用 `TaskOccurrence` / `CompletionEvent` 保存稳定历史，避免删除任务或修改规则改变过去的统计。
- AI 输出候选变更集和 diff，不直接覆盖；已完成任务、睡眠边界和锁定时间不可被模型改写。
- 未来 7 天视图、跳过某次 occurrence、截止日期和规则例外。
- EventKit 日历读写、App Intents/快捷指令、WidgetKit 真桌面小组件。
- 云同步应在 UUID、时区、删除 tombstone 和冲突合并规则明确后再做。
